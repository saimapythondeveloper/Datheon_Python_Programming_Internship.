# Stock Portfolio Performance Tracker

A Python-based utility that tracks stock portfolio performance by calculating invested capital, current market value, profit or loss, and percentage returns.

## Features
- Accepts stock ticker symbols, purchase prices, and share quantities
- Retrieves the latest available stock prices using yfinance
- Calculates profit/loss for individual holdings and the overall portfolio
- Saves performance logs to a CSV file
- Displays a formatted portfolio report in the console

## Technologies
- Python 3
- yfinance
- CSV file handling

## Installation
```bash
pip install -r requirements.txt
```

## Run the Project
```bash
python portfolio.py
```
