# Task 4: Rule-Based Interactive Terminal Chatbot

## Datheon Python Programming Internship

### 📌 Project Overview

This project is a rule-based interactive terminal chatbot developed using Python. It provides automated responses to user queries related to business hours, internship project submission, and certificate information.

The chatbot uses a JSON file to store FAQ data and Regular Expressions (Regex) to recognize user intents.

### 🚀 Features

- Greeting Recognition
- FAQ-Based Responses
- JSON File Handling
- Regex-Based Intent Matching
- Multi-Intent Recognition
- Fallback Responses for Unknown Queries
- Interactive Terminal Interface
- Exit Commands (`bye`, `exit`, `quit`)

### 🛠️ Technologies Used

- Python 3
- JSON
- Regular Expressions (`re`)
